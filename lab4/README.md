# Лабораторная работа №4. Карты теней

Проект продолжает [лабораторную №3](https://github.com/annplv/CG_labs/tree/main/lab3). Анимированная пирамида отбрасывает две тени на однотонный пол. Одну создаёт направленный источник (солнце), вторую — первый прожектор. Материалы пирамиды, анимация и управление камерой взяты из предыдущей работы.

## Запуск в Windows

Требуются CMake, Vulkan SDK и Visual Studio 2022. Из папки lab4:

```cmd
cmake --preset msvc-debug
cmake --build build-debug --config Debug
build-debug\Debug\vulkan-starter-app.exe
```

## Как получается тень

**1. Смотрим на сцену из источника света.** В `source/scene.cpp` функция `sunShadowMatrix` задаёт ориентацию солнца через `lookAt` и строит ортографическую проекцию. Солнечные лучи параллельны. У прожектора лучи расходятся из одной точки, поэтому `spotShadowMatrix` строит перспективную проекцию с полным углом обзора, равным удвоенному внешнему полууглу конуса.

**2. Записываем ближайшую глубину.** Перед основным проходом каждого кадра `renderShadowMap` в `source/application.cpp` рисует пирамиды и пол в отдельную карту глубины 1024 × 1024 для каждого из двух источников. Проход ограничивают `vkCmdBeginRendering` и `vkCmdEndRendering`. У конвейера только вершинный шейдер `shaders/shadow.vert`. Он умножает позицию на матрицу модели и матрицу источника. Тест глубины оставляет ближайшую поверхность. `vkCmdSetDepthBias` задаёт постоянную и зависящую от наклона составляющие сдвига. Барьер после прохода делает записанную глубину доступной фрагментному шейдеру.

**3. Сравниваем глубины при рисовании с камеры.** В `shaders/lit.frag` функция `visibility` делит координаты источника на `w`, переводит XY в текстурные координаты и передаёт глубину Z в `sampler2DShadow`. Сэмплер с `compareEnable = VK_TRUE` и `VK_COMPARE_OP_LESS` возвращает 1, если проверяемый фрагмент ближе записанной глубины, и 0, если перед ним есть поверхность. За пределами карты принимается видимость 1.

**4. Учитываем источник отдельно.** Результат сравнения умножается только на вклад соответствующего источника в освещение. В солнечной тени пол всё ещё может освещаться прожектором. Фоновое освещение и собственное свечение материала сохраняются.

Пол задаёт функция `makeFloor` в `source/geometry.cpp`. Это два треугольника на высоте `y = −1,5`. И для карты глубины, и для изображения с камеры используется общая функция `drawSurfaces`, поэтому положение движущихся пирамид совпадает в обоих проходах.
