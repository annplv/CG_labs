# Лабораторная работа №2. Камера и освещение

**Вариант 6: пирамида.** Продолжение [лабораторной №1](../lab1).

На основе [стартового проекта](https://github.com/vladeemerr/vulkan-starter-app) преподавателя: Vulkan, GLFW, Dear ImGui.

## Что сделано

**Базовое задание.** Пирамиды рисуются относительно камеры. Позиция, поворот (yaw, pitch) и угол обзора камеры меняются в интерфейсе. Нормали вершин генерируются процедурно, по векторному произведению рёбер каждой грани. Освещение рассчитывается по модели Блинна-Фонга во фрагментном шейдере. В интерфейсе настраиваются рассеянный свет, направленный источник и материал: альбедо, цвет блика, коэффициент блика.

**Дополнительные задания**
1. Два набора дескрипторов. Набор 0 (сцена): uniform-буфер с матрицей view-projection, позицией камеры, рассеянным и направленным светом и числом источников, плюс два storage-буфера с источниками. Набор 1 (модель): матрица трансформации, матрица нормалей и материал; у каждой пирамиды свой.
2. Массив точечных источников в storage-буфере с затуханием по закону обратных квадратов. Источники можно добавлять и удалять, у каждого меняются позиция, цвет и интенсивность.
3. Массив прожекторов в storage-буфере с затуханием по закону обратных квадратов. Если внешний угол больше внутреннего, край мягкий. Прожекторы можно добавлять и удалять, у каждого меняются позиция, направление, цвет, интенсивность и углы.
4. Визуализация источников, её можно показать или скрыть. Точечные источники и прожекторы показаны кубиками цвета источника, у прожекторов дополнительно рисуется конус белыми линиями. Всё это рисуется отдельным пайплайном с постоянным цветом, без освещения.

## Сборка и запуск (Windows)

Требуются CMake и Vulkan SDK. Из папки lab2 в x64 Native Tools Command Prompt:

```cmd
cmake --preset debug
cmake --build build-debug --parallel
build-debug\vulkan-starter-app.exe
```

## Структура

- `source/geometry` — пирамида и куб, генерация нормалей
- `source/scene` — камера, пирамиды, траектория, материал, источники света
- `source/transform` — матрицы
- `source/ui` — интерфейс ImGui
- `source/application` — код Vulkan
- `shaders/lit.*` — освещение по Блинну-Фонгу
- `shaders/unlit.*` — визуализация источников
