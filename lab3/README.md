# Лабораторная работа №3. Текстурирование

**Вариант 6: пирамида.** Продолжение [лабораторной №2](../lab2).

На основе [стартового проекта](https://github.com/vladeemerr/vulkan-starter-app) преподавателя: Vulkan, GLFW, Dear ImGui.

## Что сделано

**Базовое задание.**
- Альбедо пирамиды берётся из текстуры вместо сплошного цвета и цвета вершин.
- Изображения загружаются из папки `textures` библиотекой [stb_image](https://github.com/nothings/stb), она декодирует PNG, JPEG, BMP, TGA и другие форматы. Каждое изображение копируется в VRAM: сначала в staging-буфер, затем командой `vkCmdCopyBufferToImage`. Раскладка изображения меняется барьерами `UNDEFINED → TRANSFER_DST_OPTIMAL → SHADER_READ_ONLY_OPTIMAL`.
- У вершин есть позиция, нормаль и текстурные координаты, их генерирует `makePyramid`. На основание натягивается вся текстура: `uv = (x + 0.5, 0.5 − z)`. Боковая грань получает треугольник `(0, 1), (1, 1), (0.5, 0)`: картинка стоит на основании грани и не отражена зеркально.
- Свойства пирамид (матрица модели, матрица нормалей, блик) лежат в одном динамическом uniform-буфере, это массив структур `ModelData`. Шаг между элементами округлён вверх до `minUniformBufferOffsetAlignment`. Смещение элемента передаётся при привязке набора дескрипторов, последним аргументом `vkCmdBindDescriptorSets`.
- Вершинные и индексные буферы лежат в VRAM (`VMA_MEMORY_USAGE_AUTO_PREFER_DEVICE`, без доступа CPU). Данные сначала пишутся в staging-буфер, затем копируются командой `vkCmdCopyBuffer`. Поэтому конус прожектора теперь не пересчитывается каждый кадр: это один меш единичного конуса, а положение, направление и угол задаёт матрица.

**Дополнительные задания.**
1. Три материала: камень, дерево, лава. Текстура выбранной пирамиды выбирается из выпадающего списка `Texture`. У каждого материала свой набор дескрипторов 1. В нём один и тот же динамический uniform-буфер и свои пары изображение-сэмплер.
2. Нетривиальное сэмплирование включается флажком `Animated sampling` у выбранной пирамиды. Флаг и время передаются в push-константах (`{ float time; uint flags; }`, только фрагментный шейдер), данные модели в uniform-буфере не меняются. Каналы цвета читаются из одной и той же текстуры альбедо тремя выборками с разными координатами: красный со смещением `+offset`, зелёный без смещения, синий со смещением `−offset`. Смещение `offset = 0.03 (cos t, sin t)` вращается по окружности, поэтому по краям рисунка бегут цветные каёмки. Цвет модулируется оттенком, который плавно переходит от тёплого `(1, 0.8, 0.6)` к холодному `(0.6, 0.8, 1)` по закону `0.5 + 0.5 sin(0.5 t)`.
3. Карты блика (specular) и свечения (emissive) вместе с альбедо. Цвет блика в Блинне-Фонге умножается на карту блика. Карта свечения прибавляется к цвету после Блинна-Фонга, минуя освещение, поэтому трещины лавы светятся в темноте. Если у материала нет карты, вместо неё привязывается служебная текстура из одного чёрного пикселя: блик умножается на 0, к цвету прибавляется 0.

| Материал | Альбедо | Блик | Свечение |
|---|---|---|---|
| Stone | есть | есть: блестят камни, щели матовые | нет |
| Wood | есть | нет | нет |
| Lava | есть | нет | есть: сгенерирована из шума Перлина |

**Наборы дескрипторов.** Набор 0 (сцена) не изменился со второй лабы. Набор 1 (модель и материал):

| binding | тип | содержимое |
|---|---|---|
| 0 | `UNIFORM_BUFFER_DYNAMIC` | `ModelData` пирамиды (смещение при привязке) |
| 1 | `COMBINED_IMAGE_SAMPLER` | альбедо |
| 2 | `COMBINED_IMAGE_SAMPLER` | блик |
| 3 | `COMBINED_IMAGE_SAMPLER` | свечение |

Альбедо и свечение хранятся в формате `R8G8B8A8_SRGB`: при чтении GPU переводит их в линейные значения, в которых считается освещение. Карта блика хранит данные (долю блика), поэтому она в `R8G8B8A8_UNORM`. Сэмплер один на все текстуры: линейная фильтрация и адресация `REPEAT`, которая нужна для смещённых координат.

## Сборка и запуск (Windows)

Требуются CMake, Vulkan SDK и Visual Studio 2022. Из папки lab3:

```cmd
cmake --preset debug
cmake --build build-debug --config Debug --parallel
build-debug\Debug\vulkan-starter-app.exe
```

Генератор Visual Studio собирает несколько конфигураций в одной папке, поэтому конфигурация задаётся флагом `--config`, а exe попадает в подпапку `Debug`.

Запускать из папки lab3: программа ищет шейдеры в `shaders`, а изображения в `textures`.

Чтобы увидеть свечение лавы, уменьшите `Intensity` рассеянного и направленного света.

## Структура

- `source/geometry` — пирамида с текстурными координатами, куб и конус для визуализации источников
- `source/scene` — камера, пирамиды, траектория, материал (список текстур), источники света
- `source/transform` — матрицы
- `source/ui` — интерфейс ImGui
- `source/application` — код Vulkan: буферы в VRAM, текстуры, дескрипторы, отрисовка
- `shaders/lit.*` — текстуры и освещение по Блинну-Фонгу
- `shaders/unlit.*` — визуализация источников
- `textures` — изображения материалов
