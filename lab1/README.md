# Лабораторная работа №1. Основы 3D-графики

**Вариант 6: пирамида.**

Построить пирамиду, спроецировать её на плоскость экрана и отрисовывать в реальном времени с помощью Vulkan. Проекцию и трансформации объекта можно менять во время работы программы.

На основе [стартового проекта](https://github.com/vladeemerr/vulkan-starter-app) преподавателя: Vulkan, GLFW, Dear ImGui.

Отчёт: [reports/309_Полевая_Лаб1.pdf](reports/309_Полевая_Лаб1.pdf)

## Что сделано

1. Переключение перспективной и ортографической проекций.
2. Позиция, поворот и масштаб по осям в интерфейсе.
3. Движение и вращение по волнистой траектории: пауза, скорость, радиус, высота и число волн.
4. Выбор цвета фигуры.
5. Цвета вершин по их положению, умножаются на цвет из интерфейса.
6. Несколько пирамид (до 8), у каждой свой uniform-буфер и свой `VkDescriptorSet`.


## Сборка и запуск (Windows)

Требуются CMake и Vulkan SDK. Из папки lab1 в x64 Native Tools Command Prompt:

```cmd
cmake --preset debug
cmake --build build-debug --parallel
build-debug\vulkan-starter-app.exe
```

## Структура

- `source/geometry` — пирамида
- `source/transform` — матрицы
- `source/scene` — камера и траектория
- `source/ui` — интерфейс ImGui
- `source/application` — код Vulkan
- `shaders/` — вершинный и фрагментный шейдеры
